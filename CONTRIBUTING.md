# Contributing to FranzPLAY

Thank you for your interest! FranzPLAY is at an early stage and is being built step by step.

## Before your first contribution

FranzPLAY is dual-licensed (AGPL-3.0 and a commercial license, see [`README.md`](README.md#license)).
To keep that possible, every contributor must sign a **Contributor License Agreement (CLA)**
before their first pull request is merged. The CLA is not published yet: please open an issue
first to talk about what you would like to change.

## How we work

The rules and conventions are in [`CLAUDE.md`](CLAUDE.md) (in Italian). In short:

- One pull request does one thing, with tests.
- `make check` must pass before you push.
- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/).
- Code and code comments are in English.
